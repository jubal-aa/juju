# 🍱 어르신 식생활용품 전달 & 안부 모니터링 관리 시스템

> **취약계층 어르신 식생활 지원(밑반찬, 빵 등)의 서류 간소화 및 디지털 일괄 관리를 위한 현장 맞춤형 솔루션**

---

## 📌 1. 프로젝트 개요
매주 월요일부터 금요일까지 진행되는 독거 어르신 및 취약계층 대상 **밑반찬, 빵, 식생활용품 정기 전달 사업**에서 발생하는 번거로운 종이 서류 작업을 간소화하기 위해 제작되었습니다.  

봉사자 및 현장 실무자가 모바일 또는 PC에서 즉시 입력하고, 실시간으로 통합 관리 대장에 누적하여 **안부 이상 징후 조기 발견**, **다각도 검색**, **엑셀(CSV) 일괄 추출**을 지원합니다.

---

## ✨ 2. 주요 기능

### 1) 간편 디지털 입력 & 제출
* **일시 자동 입력:** 페이지 접속 시 현재 날짜 및 시간이 기본값으로 설정되어 빠른 기록 가능
* **업무 구분 (내 업무 vs 대신 업무):** 본인 정규 담당(`👤 내 업무`)인지, 동료의 병가·휴가 등으로 인한 대직(`🔄 대신 업무`)인지 원터치 체크 및 원래 담당자 성함 기록 지원
* **어르신 상세 정보:** 성함뿐만 아니라 **연락처(전화번호)**와 **댁 주소**를 함께 입력하여 대상자 관리 용이
* **품목 및 수량 분류:** 밑반찬, 빵·간식, 국·찌개, 기타용품 원터치 태그 선택 및 단위 설정
* **당일 컨디션 4단계 체크:**
  * 🟢 **양호:** 식사 잘하시고 안색 좋으심
  * 🔵 **보통:** 거동 약간 불편하시나 상태 안정적
  * 🟡 **주의:** 감기, 식욕 부진, 통증 호소 (모니터링 필요)
  * 🔴 **위험/응급:** 연락 두절, 문 잠김, 낙상 의심 등 즉시 복지센터 보고 대상
* **인증 사진 첨부:** 모바일 현장에서 즉시 카메라 촬영 및 사진 첨부 (썸네일 미리보기 & 클릭 시 확대)
* **방문 특이사항 및 개선사항:** 어르신 요청사항(파스 필요, 병원 일정 등) 메모

### 2) 다각도 스마트 검색 & 빠른 필터링 기능
* **🔍 전체 통합검색:** 성함, 주소, 연락처, 품목명, 담당자 중 일치하는 항목을 한 번에 검색
* **👤 어르신 성함 검색:** 대상자 성함으로 핀포인트 조회
* **🏠 댁 주소 검색:** 동·호수나 도로명 주소로 검색 (예: `102동`, `희망로`)
* **📞 전화번호 검색:** 하이픈(`-`) 유무와 무관하게 숫자 매칭 검색 (예: `010-2345` 또는 `0102345`)
* **📦 후원 물품명 검색:** 품목명이나 반찬 종류로 검색 (예: `단팥빵`, `미역국`)
* **🔄 원래 담당자 검색:** 대신 수행한 동료 이름으로 대직 내역 조회
* **원터치 빠른 필터:** [전체보기], [오늘 전달건], [👤 내 업무만], [🔄 대신 업무만], [주의·위험 가구만] 지원

### 3) 후원 담당자 검토·승인 및 생활지원사 기록 수정·보완 (신규)
* **원터치 담당자 확인(승인):** 대장 목록에서 `[미확인]` 버튼을 클릭하여 담당자 서명과 함께 `[확인완료]`로 즉시 전환
* **누락 정보 수정 모달:** 생활지원사가 현장에서 미처 적지 못한 어르신 상세 주소, 연락처, 품목명, 수량, 특이사항 등을 언제든 `[수정(✏️)]` 버튼을 통해 보완 가능
* **담당자 보완 메모:** 후원처 보고용 확인 사항, 조치 내역(예: 보건소 연계, 추가 후원물품 증빙 등)을 전용 메모란에 기록
* **검토 상태별 필터:** `[⏳ 미확인(검토대기)]` 필터로 아직 확인하지 않은 신규 전달 건만 빠르게 취합 및 처리

### 4) 일괄 대장 관리 & 모니터링
* **실시간 대시보드:** 전체 누적 전달 건수, 오늘 전달 건수, 업무 구분(내 업무/대신 업무), 담당자 검토 현황(확인완료/미확인), 안부 주의/위험 현황 카드 제공
* **안전한 로컬 저장:** 웹 브라우저 로컬 저장소(LocalStorage)를 활용하여 인터넷 연결이 불안정하거나 창을 닫아도 데이터 영구 보존

### 5) 원클릭 데이터 내보내기 & 인쇄
* **📊 엑셀(CSV) 다운로드:** 후원 담당자 확인 여부, 확인자명, 담당자 보완메모가 모두 포함된 엑셀 파일 추출 (한글 깨짐 방지 UTF-8 BOM 적용)
* **🖨️ 보고서 인쇄:** 기관/센터 제출용으로 최적화된 A4 인쇄 레이아웃 지원

## 🚀 3. 사용 방법

1. 저장소를 클론(Clone)하거나 다운로드합니다:
   ```bash
   git clone https://github.com/jubal-aa/juju.git
   ```
2. 다운로드된 폴더 내의 **`어르신_식생활용품_전달관리.html`** 파일을 더블 클릭하여 크롬(Chrome) 또는 엣지(Edge) 브라우저에서 실행합니다.
   * 별도의 프로그램 설치나 서버 구동 없이 **더블 클릭만으로 즉시 사용 가능**합니다.
   * 스마트폰이나 태블릿으로 파일을 옮겨서 열어도 완벽히 동작합니다.

---

## 🛠️ 4. 기술 스택
* **Frontend:** HTML5, Modern JavaScript (ES6+), Tailwind CSS
* **Storage:** Browser LocalStorage (No Backend/Server Required)
* **Export:** Pure JavaScript CSV Generator with UTF-8 BOM
* **Version Control:** Git, GitHub

## 📋 5. 실무 현장 가이드 (복지관 / 봉사센터)
* **부재 시 대응:** 반찬이나 유제품은 변질 위험이 있으므로 어르신과 유선 통화 후 지정된 장소에 보관해 주세요.
* **이상 징후 발견 시:** 컨디션 체크에서 `🟡 주의` 또는 `🔴 위험` 상태가 발생한 경우, 담당 사회복지사 및 센터에 즉시 연락 바랍니다.
* **개인정보 보호:** 어르신의 연락처 및 거주지 정보는 후원 사업 관리 목적으로만 안전하게 취급해 주시기 바랍니다.
