# 🍱 어르신 식생활용품 전달 & 안부 모니터링 관리 시스템

> **취약계층 어르신 식생활 지원(밑반찬, 빵 등)의 서류 간소화 및 디지털 일괄 관리를 위한 현장 맞춤형 솔루션**

---

## 📌 1. 프로젝트 개요
매주 월요일부터 금요일까지 진행되는 독거 어르신 및 취약계층 대상 **밑반찬, 빵, 식생활용품 정기 전달 사업**에서 발생하는 번거로운 종이 서류 작업을 간소화하기 위해 제작되었습니다.  

생활지원사(또는 봉사자)가 현장 스마트폰/PC에서 즉시 입력하고, 후원 담당자가 실시간으로 확인(승인) 및 누락 정보를 직접 수정·보완할 수 있는 **통합 웹 기반 관리 솔루션**입니다.

---

## 👥 2. 업무 분담 워크플로우

```mermaid
flowchart LR
    A["📱 생활지원사 / 봉사자"] -->|현장 전달 & 모바일 입력| B["📝 일괄 관리 대장"]
    B -->|실시간 동기화| C["💻 후원 담당자"]
    C -->|누락 정보 보완 / 수정| B
    C -->|최종 승인 & 확인완료| D["📊 엑셀 일괄 추출 & 보고서 인쇄"]
```

* **생활지원사 (현장 실무자):** 배달 현장에서 대상자 어르신, 물품, 안부 컨디션, 사진 촬영 후 즉시 제출
* **후원 담당자 (사회복지사/관리자):** 전달 내역 실시간 검토, 미기재된 상세 정보 수정·보완, 최종 승인 및 결과보고

---

## ✨ 3. 주요 기능 및 특징

### 1) 현장 맞춤 간편 입력 & 제출
* **일시 자동 세팅:** 접속 시 현재 날짜 및 시각이 기본 입력되어 현장 작성 시간 단축
* **업무 구분 (내 업무 vs 대신 업무):**
  * `👤 내 업무 (본인)`: 정규 담당 어르신 전달
  * `🔄 대신 업무 (대직)`: 동료의 병가·휴가 등으로 인한 대리 전달 시 원래 담당자 성함 기록 지원
* **어르신 상세 정보:** 성함뿐만 아니라 **연락처(전화번호)**와 **댁 주소**를 함께 관리
* **후원 품목 분류:** 밑반찬, 빵·간식, 국·찌개, 기타용품 원터치 태그 및 상세명·수량 입력
* **어르신 안부·컨디션 4단계 체크:**
  * 🟢 **양호:** 안색 밝고 식사 잘 챙겨드심
  * 🔵 **보통:** 거동이 다소 불편하나 전반적으로 안정적
  * 🟡 **주의:** 감기, 식욕 부진, 통증 호소 등 모니터링 필요
  * 🔴 **위험/응급:** 연락 두절, 문 잠김, 낙상 의심 등 즉시 복지센터 보고 대상
* **인증 사진 첨부:** 모바일 카메라 연동 촬영 및 사진 파일 첨부 (썸네일 & 확대 모달 지원)
* **현장 메모:** 건강 상태, 식단 기호, 요청사항 메모

### 2) 후원 담당자 검토·승인 및 누락 기록 수정 기능
* **원터치 승인 토글:** 목록에서 `[미확인]` 버튼을 클릭하면 담당자 성함과 함께 `[✅ 확인완료]`로 즉시 전환
* **누락 기록 수정 모달 (`✏️`):** 생활지원사가 미처 적지 못한 주소, 연락처, 품목명, 수량, 특이사항을 언제든 팝업창에서 직접 수정 및 보완
* **담당자 전용 보완 메모:** 후원처 보고용 확인 사항, 보건소 진료 연계 등 관리자 조치 내역 별도 보관
* **검토 대기 전용 필터:** `[⏳ 미확인(검토대기)]` 버튼으로 아직 확인하지 않은 신규 등록 건만 모아보기 가능

### 3) 다각도 스마트 검색 & 상태 필터링
* **드롭다운 선택형 전용 검색:**
  * 🔍 전체 통합검색 (성함, 주소, 연락처, 품목, 담당자, 보완메모 일괄 검색)
  * 👤 어르신 성함 검색
  * 🏠 댁 주소 검색 (동·호수, 도로명)
  * 📞 전화번호 검색 (하이픈 유무 무관 스마트 매칭)
  * 📦 후원 물품명 검색
  * 🔄 원래 담당자 검색 (대직 내역 추적)
  * 📝 담당자 보완메모 검색
* **상태 필터 탭:**
  * `[전체보기]` | `[⏳ 미확인(검토대기)]` | `[✅ 확인완료]` | `[🔄 대신업무]` | `[주의·위험]`

### 4) 주별(Weekly) 및 월별(Monthly) 단위 기간 검색 (신규)
* **원터치 빠른 기간 선택:** `[전체 기간]`, `[오늘]`, `[이번 주 (월~금)]`, `[지난 주]`, `[이번 달]`, `[지난 달]` 원클릭 필터링
* **📅 주별(Weekly) 단위 검색:** 기준 날짜를 선택하면 해당 주간(월~일/금) 자동 계산 및 `◀ 이전 주` / `다음 주 ▶` 단위 이동
* **🗓️ 월별(Monthly) 단위 검색:** 연·월(`YYYY-MM`) 선택기를 통해 해당 월 전체 전달 내역 조회 및 `◀ 이전 달` / `다음 달 ▶` 단위 이동
* **스마트 기간별 엑셀 다운로드:** 선택된 주간/월간 데이터만 골라 엑셀 파일로 추출하며, 파일명에도 해당 기간(예: `이번주`, `이번달`, `2026-10-05_2026-10-11`)이 자동으로 반영됨

### 5) 실시간 대시보드 및 안전한 데이터 보존
* **5종 통계 카드:** 전체 누적 전달, 오늘 완료, 업무 구분(내 업무/대신), 담당자 검토 현황(확인/미확인), 주의·위험 가구 현황
* **브라우저 LocalStorage 자동 저장:** 인터넷 연결이 불안정하거나 창을 닫아도 데이터 영구 보존

### 6) 엑셀(CSV) 다운로드 & 인쇄 최적화
* **📊 엑셀(CSV) 추출:** 담당자 승인 여부, 확인자명, 보완메모까지 모든 열이 완벽히 포함된 엑셀 파일 생성 (한글 깨짐 없는 UTF-8 BOM 탑재)
* **🖨️ 깔끔한 A4 인쇄 레이아웃:** 불필요한 버튼과 입력 폼을 숨기고 관리 대장 표만 깔끔하게 출력/PDF 저장

## 🚀 4. 실행 및 사용 방법

1. 저장소를 클론(Clone)하거나 다운로드합니다:
   ```bash
   git clone https://github.com/jubal-aa/juju.git
   ```
2. 다운로드된 폴더 내의 **`어르신_식생활용품_전달관리.html`** 파일을 더블 클릭하여 크롬(Chrome) 또는 엣지(Edge) 브라우저에서 실행합니다.
   * 별도의 웹 서버나 데이터베이스 설치 없이 **단일 HTML 파일로 즉시 실행**됩니다.
   * 스마트폰(카카오톡, 메일 전달 등)으로 파일을 열어도 동일하게 동작합니다.

## 🛠️ 5. 기술 스택
* **Frontend:** HTML5, Modern JavaScript (ES6+), Tailwind CSS
* **Storage:** Browser LocalStorage (No External Server/DB Required)
* **Export Engine:** Client-side CSV Generator with UTF-8 BOM
* **Version Control:** Git, GitHub

## 📋 6. 현장 실무 가이드 (복지관 / 주민센터 / 봉사센터)
* **식생활용품 보관 안내:** 반찬 및 유제품은 변질 위험이 크므로 부재 시 임의로 문고리에 걸지 마시고, 반드시 유선 연락 후 보관 장소를 확인해 주세요.
* **위기 징후 발견 시 즉시 조치:** 컨디션 체크에서 `🟡 주의` 또는 `🔴 위험` 가구가 확인되면 후원 담당자와 담당 사회복지사에게 즉시 보고 바랍니다.
* **개인정보 취급:** 어르신의 연락처 및 거주지 정보는 후원 사업 관리 목적으로만 안전하게 관리됩니다.
